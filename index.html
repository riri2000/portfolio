EmbedWatch

Projet personnel

Personal project

Un simulateur d'objets connectés : des capteurs virtuels publient leurs mesures par MQTT vers un serveur qui les enregistre et les affiche en direct dans le navigateur. Si la connexion tombe, l'appareil garde ses mesures en mémoire et les renvoie à la reconnexion. Les tests d'intégration tournent contre un vrai broker Mosquitto.

A simulator for connected devices: virtual sensors publish their readings over MQTT to a server that stores them and shows them live in the browser. If the connection drops, the device holds its readings and sends them again once it reconnects. The integration tests run against a real Mosquitto broker.

Python, FastAPI, MQTT (Mosquitto), WebSocket, SQLite
